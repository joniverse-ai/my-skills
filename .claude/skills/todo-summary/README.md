# todo-summary

## 이 스킬이 필요한 이유

하루가 끝날 때 "오늘 뭘 했지?"를 떠올리며 정리하는 건 생각보다 시간이 걸린다.
할 일 목록에서 완료된 항목을 하나하나 확인하고, 그걸 다시 커밋 메시지나 일일 보고 형식으로 옮기는 작업은 반복적이다.

이 스킬은 `node todo.js summary` 한 번으로 오늘 완료한 할 일을 자동으로 가져와 보여준다.
매일 퇴근 전 작업 기록을 남기거나, 스탠드업 미팅 준비를 할 때 유용하다.

## 사용 예시

```
/todo-summary
```

실행하면 오늘 완료한 항목을 요약해서 보여준다:

```
- DB 마이그레이션 스크립트 작성
- 회원가입 API 에러 핸들링 추가
- 테스트 코드 커버리지 80% 달성
```
